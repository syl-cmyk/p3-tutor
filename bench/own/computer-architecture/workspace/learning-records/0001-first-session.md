# A cache miss, and how an address is split into tag, index and offset

The learner can explain why a cache access misses, and can split a memory address into its tag, index and offset.
The learner sees that the address decides where in the cache to look, and that the tag is what shows whether the data found there is the right one.

**Evidence:** Split an example address into tag, index and offset on their own, and explained why an access with a matching index but a different tag is a miss.

**Implications:** Pipelining was introduced after this session.
Why a pipeline stalls, and how it handles a hazard, has not been taught.
