# Computer Architecture (Pipelining) Resources

## Knowledge

- [Utah CS 250P, lecture 5: pipelining hazards](https://users.cs.utah.edu/~aburtsev/250P/2019fall/lectures/lecture05-pipelining-hazards/lecture05-pipelining-hazards.pdf)
  University lecture defining structural, data and control hazards with pipeline diagrams. Use for: the three hazard types and the first stall counts.
- [Edinburgh INF2C lecture notes](https://www.inf.ed.ac.uk/teaching/courses/inf2c/lectures/CS08_10_notes.pdf)
  Stalls as bubbles; structural and data hazards. Use for: why hardware fixes structural hazards.
- [Notre Dame CSE 30321 lecture](https://www3.nd.edu/~mniemier/teaching/2008_B_Fall/lectures/21%20-%20Lecture.pdf)
  Stalls raising CPI; read-after-write hazards. Use for: CPI with stalls.
- [Colorado State pipelining slides](https://cs.colostate.edu/~cs270/.Summer19/slides/Pipelining.pdf)
  Forwarding and load-use stalls. Use for: the next lesson on how hazards are handled.
- [Western Ontario CS 3350 notes](https://www.csd.uwo.ca/~mmorenom/cs3350_moreno.Winter-2015/notes/L6-ILP-2.pdf)
  Control hazard cost and branch handling. Use for: branch penalty and prediction.

## Wisdom (Communities)

- [Computer Science Stack Exchange](https://cs.stackexchange.com/)
  Moderated Q&A. Use for: checking a cycle count or a hazard diagnosis with others.
