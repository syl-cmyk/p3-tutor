Context and memory in an agent

From lesson 1.

Terms

  • Context: the tokens the model sees on one call (system prompt, tool descriptions, history, tool results).
  • Context window: the maximum size of that context.
  • Compaction: summarize the history and restart from the summary (lossy).
  • Retrieval: fetch only the relevant piece of a large store into the context.

Where does it go?

QuestionIf yes
Needed on every call, and short?System prompt (context)
Must outlive the session and be exactly right?Database, read by a tool
Must outlive the session, soft preference?Notes the model writes and reads
Source too big to hold?Retrieval (skip it if under about 200,000 tokens)
Only needed for a few steps?Context, then clear it

Cost rule

Input tokens of call n = everything before it + the new result. Total cost = the sum over all calls, so a big tool result is paid for again on every later call.
