# Knife Skills Resources

## Knowledge

- [Article: "Different Knives and the Best Uses for Each One" (Escoffier)](https://escoffier.edu/blog/culinary-arts/different-knives-and-the-best-uses-for-each)
  Culinary-school guide to knife types. Use for: which knife suits which job.
- [Rouxbe: Types of Knife Cuts](https://rouxbe.com/tips-techniques/495)
  Professional online cooking school's cut sizes. Use for: dimensions of julienne, batonnet and dice.
- [Wikipedia: List of culinary knife cuts](https://en.wikipedia.org/wiki/List_of_culinary_knife_cuts)
  Reference list of cuts with typical sizes. Use for: checking a cut's name and size; sizes differ a little between books.
