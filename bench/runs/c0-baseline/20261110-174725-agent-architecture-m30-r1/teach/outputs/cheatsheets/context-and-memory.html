Context and memory in an agent

From lesson 1.

Terms

  • Context window: all the text the model can see in one call, including its own output. Fixed size, counted in tokens.
  • Counts toward it: system prompt, tool definitions, every message and tool result, the model's output.
  • Context rot: recall gets worse as the context fills.
  • Session: one conversation, one message list. A new session starts empty.

Rules

  • The model keeps nothing between calls; the program re-sends the whole message list.
  • Each step re-reads everything before it, so large tool results are paid for again at every later step.
  • Nothing carries across sessions unless the program saves it and loads it.
  • The memory tool is client-side: the model requests, the program carries out.

Where information goes

Keeping context small

  • Clear tool results already used.
  • Summarize (compaction) a long conversation; save what must survive elsewhere.
  • Make tools return less, such as one day's free slots, not the whole month.
