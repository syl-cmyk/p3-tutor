Context and memory in an agent

From Lesson 1.

  • Context window: everything the model is given in one call (system prompt, tool descriptions, messages, tool results) plus its reply. The model can use only this.
  • Each step resends the window. Input tokens per call = everything so far; total cost = the sum over calls.
  • Context rot: recall degrades as the window fills. A bigger window is headroom, not a design.
  • Between sessions the model keeps nothing. Your program must save facts and load them back.
