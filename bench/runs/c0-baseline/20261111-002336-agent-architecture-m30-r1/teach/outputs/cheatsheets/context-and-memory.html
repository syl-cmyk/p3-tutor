Context and memory in an agent

From lesson 1.

Terms

  • Context: the tokens given to the model for one call: system prompt, tool definitions, messages, tool results, plus its response.
  • Context window: the most tokens one call can hold.
  • Context rot: recall and accuracy get worse as the context grows.
  • Compaction: summarize the history and continue from the summary.
  • Retrieval: search a store, add only the best chunks to context.
  • Notes: facts saved outside the context and loaded back later.

Rules to remember

  • The model keeps nothing between calls; your program resends the history, so every step costs more than the last.
  • Nothing survives between sessions unless your program saves it and loads it back.
  • A bigger window is room, not a reason to fill it.
  • Save facts, not transcripts. Gating facts (training status) come from a trusted record, looked up with a tool.
