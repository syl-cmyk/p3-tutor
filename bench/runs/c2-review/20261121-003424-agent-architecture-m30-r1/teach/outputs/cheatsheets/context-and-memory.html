Live toolFacts that change by the hourCalendar availability

Rules

  • The model keeps nothing between calls: the program re-sends the context each time.
  • Tokens sent per call × number of calls drives cost; the window size is only a ceiling.
  • Trim: small tool results, clear used ones, summarize very long tasks.
  • Notes: save stable facts with dates, and check the real source for anything important.
  • Retrieval: give each chunk its source (machine and section); return few chunks.
