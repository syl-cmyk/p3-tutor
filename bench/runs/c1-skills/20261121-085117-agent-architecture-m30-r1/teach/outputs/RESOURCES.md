# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context as a finite resource, context rot, just-in-time retrieval, compaction, note-taking, sub-agents. Use for: anything on what goes in the window and what stays out.
- [Article: "Managing context on the Claude Developer Platform" (Anthropic)](https://www.anthropic.com/news/context-management)
  The memory tool (file-based, client-side storage) and context editing. Use for: how notes persist between sessions.
- [Docs: Claude Code context window](https://code.claude.com/docs/en/context-window.md)
  What loads into context at session start, including the memory file limits. Use for: a concrete example of bounded notes.
- [Paper: "Retrieval-Augmented Generation for Natural Language Processing: A Survey"](https://arxiv.org/pdf/2407.13193)
  Survey of chunking, embeddings and retrieval. Use for: deeper reading on the retrieval pipeline.
