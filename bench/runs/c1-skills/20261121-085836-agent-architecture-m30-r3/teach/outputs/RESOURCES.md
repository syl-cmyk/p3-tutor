# Agent architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Anthropic engineers on what to put in an agent's context and why. Use for: deciding what the assistant keeps in context.
- [Context windows (Claude docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window fills and what happens at the limit. Use for: token limits and cost reasoning.
- [Memory tool (Claude docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Memory as files your code stores, across conversations. Use for: designing notes between sessions.
- [Managing context on the Claude platform (Anthropic)](https://www.anthropic.com/news/context-management)
  Context editing and the memory tool together. Use for: trimming old tool results in long loops.
- [Contextual retrieval (Anthropic)](https://www.anthropic.com/engineering/contextual-retrieval)
  Chunking, embeddings, keyword search and re-ranking, with measured results. Use for: finding the right page in a long manual.
