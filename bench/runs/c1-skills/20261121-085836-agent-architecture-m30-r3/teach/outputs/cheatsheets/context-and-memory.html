Where information lives

PlaceLastsUse for
Context windowOne requestThe conversation, tool results, rules
Saved notesAcross sessionsSoft facts such as preferences
Database toolPermanent, exactTraining status, bookings
Retrieval indexPermanent, read-onlyLong manuals

Rules to remember

  • The model keeps nothing between calls; the program re-sends what it needs.
  • Input tokens for call n = everything before it, so each step costs more than the last.
  • Tokens in the window are paid for again on every later call.
  • A new session starts empty: load notes in, save new ones out.

Retrieval steps

  1. Once: split manuals into chunks, add a short context line to each, index them.
  2. Per question: search (keyword for exact codes, embeddings for similar meaning, both if you can).
  3. Return only the top few chunks into the window.
