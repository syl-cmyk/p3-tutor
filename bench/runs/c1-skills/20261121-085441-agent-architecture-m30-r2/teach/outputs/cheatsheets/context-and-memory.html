Searchable storeLarge documents split into chunksPermanent; only the top chunks enter the windowMachine manuals

Rules of thumb

  • Input cost = the sum of the whole context on every call. A result stays billed until you clear it.
  • Over the window or rotting: clear old tool results first, then compact (summarize).
  • Knowledge base under about 200,000 tokens: try the whole thing in the prompt with caching before building search.
  • Search: embeddings match meaning, BM25 matches exact words; use both. Prepend context to each chunk before indexing.
  • Facts where a mistake is costly (training status) live in a database the program reads, not in a note the model wrote.
