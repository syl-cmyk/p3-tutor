# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic)](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents)
  Primary source on what goes in the context window, context rot, notes and retrieval. Use for: deciding what the assistant keeps in context.
- [Article: "Managing context on the Claude Developer Platform" (Anthropic)](https://www.anthropic.com/news/context-management)
  Introduces the memory tool (file-based, client-side) and clearing old tool results. Use for: saving things between sessions.
- [Article: "Building effective agents" (Anthropic)](https://www.anthropic.com/research/building-effective-agents)
  Treats retrieval, tools and memory as augmentations of a model. Use for: workflows versus agents and overall architecture.
- [Article: "Effective Context Engineering for AI Agents: A Developer's Guide" (Machine Learning Mastery)](https://machinelearningmastery.com/effective-context-engineering-for-ai-agents-a-developers-guide/)
  Practitioner guide, secondary source. Use for: filtering retrieved results and keeping notes up to date.
