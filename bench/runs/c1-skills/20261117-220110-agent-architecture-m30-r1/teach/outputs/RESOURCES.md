# Agent Architecture Resources

## Knowledge

- [Anthropic: Effective context engineering for AI agents](https://anthropic.com/research/effective-context-engineering-for-ai-agents)
  Context rot, just-in-time retrieval, compaction, note-taking, subagents. Use for: deciding what stays in context and what goes outside it.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how turns accumulate, compaction and context editing. Use for: exact rules on tokens and limits.
- [Claude docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file memory in a /memories folder, and security rules. Use for: designing what the assistant saves between sessions.
- [Anthropic: Contextual Retrieval](https://anthropic.com/news/contextual-retrieval)
  Chunking, embeddings, BM25, hybrid search, retrieval failure rates. Use for: finding the right page in a long manual.
