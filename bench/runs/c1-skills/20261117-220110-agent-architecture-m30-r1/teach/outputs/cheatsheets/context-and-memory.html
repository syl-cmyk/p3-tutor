Rules of thumb

  • The model sees only what is in the call. The program resends the whole history every step.
  • Input cost = sum over calls of the context size at each call (4 calls: 1,530 + 1,980 + 4,430 + 4,630 = 12,570).
  • A fuller window can mean worse recall (context rot): keep it small.
  • Nothing carries across sessions unless the program saves it and loads it back.
  • Retrieval: chunk the manual, search (meaning via embeddings and exact words via BM25), put the top few chunks in context.
  • Long session: compaction (summarize and continue); put must-keep facts in notes.
