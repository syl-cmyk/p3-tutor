# Misconception to work on: the model runs the tools and remembers on its own (M4, M3)

Riley's graded quiz 0001 (s1) shows the loop and tool descriptions are understood, but the roles are blurred: Riley believes the model runs the tools itself (so q4 was answered as one model call, and q2 as the model reading the calendar) and that it remembers earlier tool choices across sessions by itself.
Next lessons should show, step by step, that the model only writes a request and each result goes into a new model call, and that memory between sessions must be saved and supplied by the program; this leads straight into context and memory.
