Context and memory in an agent

Use this to decide where each piece of the makerspace assistant's information lives: in the window, in a search, or in a saved note.

Key terms

TermPlain meaning
TokenThe unit the model reads and writes in; cost and limits are counted in it.
Context windowAll the text the model can see on one call, including its own reply.
HistoryThe list your program keeps and resends on every call.
CompactionSummarizing a long conversation and starting a new window from the summary.
RetrievalFinding the right pieces in a store outside the window and loading only those.
Notes (memory)Text saved outside the window so a later session can read it back.

The rules

  1. The model sees only the text sent on this call, because it keeps nothing itself.
  2. Every step is a new call that resends the whole history, so the window and the bill grow each step.
  3. A fuller window is not better, because accuracy degrades as it fills; trim old results or compact.
  4. Long, fixed material is retrieved, because pasting it in would resend it on every call.
  5. Anything needed next session is written to notes and read back, because the window is gone when the session ends.

Where does it go? Does it change between sessions? Then a note, with a date. Is it big and only sometimes needed? Then retrieval. Needed on every step? Then the window, kept short.

Worked example

Call 1 sends 1,440 tokens. The model asks for the calendar (60 tokens) and the result is 160 tokens. Call 2 sends 1,440 + 60 + 160 = 1,660. It asks for a manual search (50), and a 1,500-token page comes back. Call 3 sends 1,660 + 50 + 1,500 = 3,210. Total sent: 1,440 + 1,660 + 3,210 = 6,310 tokens (round numbers made up for the lesson).

Common mistakes

  • "The model remembers earlier chats." Only the text sent on this call exists for it.
  • "A bigger window solves it." Accuracy degrades as the window fills, and every call resends it all.
  • "Compaction keeps everything." A summary can drop the exact detail, so save must-keep facts as notes.
  • "Memory stores itself." Your program has to write and reload the notes.
