# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, compaction, just-in-time retrieval and note-taking. Use for: deciding what an agent keeps in its window.
- [Docs: Context windows (Claude Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Defines the window, how turns accumulate, context rot and tool result clearing. Use for: what counts toward the window and cost.
- [Docs: Memory tool (Claude Docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  How a client-side memory store works across sessions, with security cautions. Use for: saving student data between visits.
