Rules of thumb

  • Input on call n = everything before it + the new step; cost grows faster than step count.
  • Clear old tool results first; compact (summarize) if still too big.
  • Keep notes small and organized; do not dump transcripts.
  • Under about 200,000 tokens, pasting it all in is an option to price; above, retrieve.
  • Use keyword search for exact codes, meaning search for topics, and expect misses.
  • Place each fact by: how often needed, how long it must last, how big.
