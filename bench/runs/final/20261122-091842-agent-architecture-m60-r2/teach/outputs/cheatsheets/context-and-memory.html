What goes in the context window: keep, clear, fetch, save

A look-up page for deciding what an agent sees, remembers and looks up. Every number is made up for the example.

Key terms

TokenA small chunk of text the model counts; a word is not one token, and counts differ by model.
Context windowEverything the model can see on one call, including its own reply.
CallOne round trip: your program sends a request, the model sends text back.
Context rotThe model uses a fuller window worse, so more is not better.
CompactionSwapping old messages for a short summary when the history gets long.
Retrieval (RAG)Looking up only the few manual pieces that match the question.
Session / memory fileOne visit, and a small file your program stores outside the window to load next visit.

The rules

  1. Everything sent counts toward the window and the bill, because the model sees only this one call.
  2. Your program resends the whole history every call, because the model keeps nothing between steps.
  3. Clear big results once used and leave a short stub, because they are billed on every later call.
  4. Retrieve a few pieces of a long manual instead of carrying it, because you pay for every token each call.
  5. Save notes outside the window to survive a session, and re-check them with the real system before acting, because notes go stale.

Worked example

Rules 800 + tools 600 + question 20 = 1,420 tokens in on call 1. The model asks for a calendar check (40 tokens), and the result is 300 tokens.

Call 2 input = 1,420 + 40 + 300 = 1,760. Total input over both calls = 1,420 + 1,760 = 3,180, not 1,760.

Common mistakes

"A token is a word."Tokens are chunks the model's tokenizer picks; counts vary by model.
"Only my message counts."Rules and tool descriptions are sent and counted on every call.
"The model remembers earlier steps itself."Your program resends the message list; leave a result out and it is gone.
"A bigger window means I can stop choosing."Old results still cost every call, and context rot hurts.
"The model learned the student."Nothing in it changes; only the note file you load tells it.
"A note is always true."It is a dated hint; confirm with the booking system.
