Pipeline hazards: why a pipeline stalls

Look up the three causes of a stall and count the cycles it costs. Our machine: 5 stages (IF, ID, EX, MEM, WB), separate memories, no bypassing, registers written in the first half of a cycle and read in the second, branch decided at the end of EX.

Key terms

Stalla cycle where an instruction can't move on and waits
Bubblethe empty slot a stall sends down the pipeline
Hazardthe cause of a stall
Structuraltwo instructions need the same hardware in the same cycle
Dataan instruction needs a value an earlier one hasn't written yet
Controlthe next instruction isn't known because a branch isn't decided
CPIcycles per instruction: total cycles divided by instructions

Rules

  1. Ask three questions. Same hardware twice? Structural. Value not written yet? Data. Next instruction unknown? Control.
  2. Total cycles = 4 + N + stalls, because the first instruction needs 4 extra cycles to fill the pipe, N is the number of instructions, and each stall adds one cycle.
  3. Data gap (instructions between the writer and the reader): gap 0 costs 2 stalls, gap 1 costs 1, gap 2 or more costs 0, because the value is written in cycle 5.
  4. Branch cost = stages up to and including the deciding stage, minus 1. Decided at the end of EX (stage 3) means 3 − 1 = 2 stalls, taken or not, because fetch waits either way.

Worked example

A loop has 5 instructions, the last one a branch, and runs 10 times.

  1. Branch cost: 3 − 1 = 2 stalls per iteration.
  2. Stalls: 10 × 2 = 20. Instructions: N = 50.
  3. Total: 4 + 50 + 20 = 74 cycles, against 54 with no stalls.
  4. If 20% of instructions are branches, CPI = 1 + 0.2 × 2 = 1.4.

Common mistakes

  • Every stall is a data hazard. No: shared hardware and unknown branches stall too, even with different registers.
  • Pipelining makes each instruction faster. No: one instruction takes as long or longer, but many finish sooner.
  • A stall means a wrong result. No: the answer is the same, one cycle later.
  • A branch only stalls when taken. No: in our design it costs the same either way.
  • Any shared register stalls. No: two instructions that only read it don't; the problem is write, then read.
