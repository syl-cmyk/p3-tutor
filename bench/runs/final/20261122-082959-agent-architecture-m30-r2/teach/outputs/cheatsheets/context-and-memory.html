Context and memory in an agent

Look up what the model sees, what survives, and where each fact should live.

Key terms

TermPlain meaning
TokenA small chunk of text; a manual page is about 400.
Context windowAll the text the model can read for one reply, the reply included.
Context rotThe more tokens in the window, the worse the model recalls from them.
CompactionReplacing a long chat with a short summary.
Tool result clearingRemoving old tool output from the window.
Note / memory toolA file your program stores outside the window; the model asks to write or read it.
Chunk, embeddingA piece of a manual; a list of numbers that captures its meaning.
RetrievalFind the best chunks and add them to the prompt.

Rules

  1. The program re-sends the whole pile on every call, because the model keeps nothing between calls.
  2. Instructions, tool descriptions, history and results all count, because everything in the request is input.
  3. Put in the smallest set of facts that makes the right answer likely, because more tokens cost more and can recall worse.
  4. To shrink the pile, clear stale tool results or summarize, and say what must survive, because the model sees only what is left.
  5. Across sessions, save a short note outside the window and read it back, because the window is thrown away.
  6. For long manuals, retrieve only the closest chunks, because pasting everything is costly.

Where does it go? Needed on the next call: window. Needed in a later session: note (or database if it must be exact). Needed now and then from a big pile: retrieve.

Worked example

Illustrative numbers. Five calls, all manuals pasted in: 10 manuals × 120 pages × 400 tokens = 480,000 per call, so 5 × 480,000 = 2,400,000 input tokens.

Retrieve 3 pages (1,200) plus 1,800 for instructions, tools and question: 3,000 per call, 5 × 3,000 = 15,000. That is 160 times less.

Common mistakes

  • The model remembers earlier calls. It only sees what the program sends.
  • If it fits, it is fine. It still counts as input every call, and recall can drop.
  • A summary keeps the important bits. Only what the summary says survives.
  • Notes are always in the window. They count only once read.
  • Retrieval means the model learned the manuals. It only reads what came back, and it can miss.
