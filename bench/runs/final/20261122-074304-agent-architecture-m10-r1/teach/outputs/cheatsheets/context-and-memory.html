Context and memory in an agent

Use this to decide where each fact lives: in the context window, in notes, or in retrieval.

Key terms

TokenA chunk of text; models are billed by the token, so more tokens means more cost.
CallOne trip to the model: text goes in, text comes out.
Context windowAll the text the model can use on one call, including its own reply; it is working memory, not training data.
Context rotThe model gets worse at using the text as it gets longer.
CompactionSummarizing a long conversation and carrying on with the summary.
NotesFacts the program saves outside the window and loads back later.
RetrievalLooking up the relevant piece of a big source and loading just that, just in time.

Rules

  1. On each call the model knows about this chat only what is in the window, because nothing else is handed to it.
  2. Every step re-sends the whole history, because each call is fresh; so context and cost grow.
  3. Shrink the window by clearing old tool results or summarizing, because a bigger window still has context rot and costs per token.
  4. For the next session, save a note and reload it, because the window is gone when the session ends.
  5. For big sources, search and load only the best pages, because pasting everything costs its full size on every call.

Worked example (illustration numbers, not real limits)

Fixed text 1,200 tokens, student question 30: "Is the laser cutter free Friday?"

  1. Call 1 input: 1,200 + 30 = 1,230. The model asks for check_calendar (60 tokens).
  2. The program runs it; the Friday slots come back (400 tokens).
  3. Call 2 input: 1,200 + 30 + 60 + 400 = 1,690.
  4. Input paid across both calls: 1,230 + 1,690 = 2,920, not 1,690.

Manual: 120 pages × 3,000 = 360,000 tokens. Two retrieved pages = 6,000, which is 1.7% of pasting it all.

Where does it live?

WindowSmall, needed every call or right now (rules, current chat).
NotesSmall, needed in later sessions (training status).
RetrievalBig, needed rarely (a manual page).

Common mistakes

  • "The model remembers me from last time." A new call has only what it is handed.
  • "Earlier steps are free." Each call re-sends and pays for the history again.
  • "A 1M window means paste every manual." Ten 360,000-token manuals overfill it, and long contexts degrade.
  • "The model learned the student's status." The saved notes carry it; delete them and the next session starts blank.
  • "Retrieval is the model recalling." It is a program lookup, and it can return the wrong page.
