# Agent Architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Covers what context is, context rot, compaction, note-taking and just-in-time retrieval. Use for: deciding what an agent keeps in its window, saves in notes, or retrieves.
- [Docs: "Context windows" (Claude Platform Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Explains the context window as working memory, how each turn re-sends history, and how tool results count. Use for: token and cost reasoning, and window limits.
